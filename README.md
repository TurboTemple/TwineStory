# Life Sim

A text-based, modern-day life simulator built with SugarCube 2.37.3 and Tweego.

- **Play:** `https://turbotemple.github.io/TwineStory/`
- **Debug mode:** add `?debug` to the URL — `https://turbotemple.github.io/TwineStory/?debug`
  (on-screen console, test pages, validation messages)

Every push is checked and built by GitHub Actions; merging to `main` publishes
the game to GitHub Pages.

The framework specification lives in [`CLAUDE.md`](CLAUDE.md).
