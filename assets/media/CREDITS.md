# Where the pictures came from

Every picture Claude added is listed here and in `credits.json` (which the
game reads for its **Menu → Credits** page). Many of these licences (CC BY,
CC BY-SA, CC BY-NC…) require the credit, so keep both up to date: when you
remove a picture, remove its line; pictures you upload yourself only need a
line if their licence asks for credit.

"NC" licences mean the picture can't be used in a game that's sold. If the
game is ever sold, those pictures need replacing.
